# MK Chess Session Leader

A static GitHub Pages training app for MK Chess session leaders. It turns the Bletchley session checklist into replayable SVG/CSS animation scenes, with the Pairing lesson focused on matching adults with adults and juniors with juniors on separate tables where possible.

## Host on GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository settings, open Pages.
3. Set the source to the main branch and the root folder.
4. Open the published Pages URL.

No build step is required.
